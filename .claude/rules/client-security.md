HttpOnly 세션 쿠키를 사용하고 요청에 필요한 credentials를 포함한다.
로그아웃·계정 전환 시 이전 사용자 데이터와 오래된 비동기 응답이 새 세션에 반영되지 않게 한다.
API 실패를 샘플 데이터로 대체하지 않는다. 데모는 명시된 demo 모드에서만 실행한다.
DB/메일/R2 비밀키를 브라우저 코드·NEXT_PUBLIC 환경변수에 넣지 않는다.
클라이언트 버튼 숨김은 권한 검사의 대체가 아니다. 서버 오류를 실제 상태에 맞게 표시한다.
