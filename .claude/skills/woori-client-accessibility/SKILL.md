description: 화면 변경에서 키보드와 스크린리더·포커스·모션 접근성을 검토하고 보완한다.
---

접근성 스킬의 검사 방법을 우리 UI에 맞게 사용한다. 새 폴더 구조나 컴포넌트 라이브러리를 강제하지 않는다.
키보드 진입/조작/닫기, 모달 포커스 이동·복귀, 버튼 이름, 입력 오류 연결, 사진 대체 설명을 확인한다.
본문 대비 4.5:1, 큰 글자 및 UI 경계 3:1 기준을 구분한다. 44px 터치 영역은 제품 권장값이며 WCAG 2.1 AA 의무라고 오기하지 않는다.
200% 확대·모바일·reduced motion을 확인하고 실제 보조기술로 검사하지 않은 부분을 밝힌다.
자동 검사 통과를 전체 접근성 보장으로 설명하지 않는다.

출처: design:accessibility-review. 원본 절차를 프로젝트에 맞게 재작성했으며 프레임워크 구조/명명 규칙은 가져오지 않았다.
