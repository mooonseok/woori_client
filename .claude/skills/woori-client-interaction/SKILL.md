---

기존 갤러리 디자인과 동작을 기준으로 요구된 변화만 구현한다.
핀치 시작점 기준 줌, 배율 제한, 확대 상태 팬, 축소 시 경계 복귀, 단일 탭/더블 탭/스와이프 충돌을 확인한다.
애니메이션 중 재입력·닫기·화면 이동·컴포넌트 해제와 요청 취소를 처리한다. 모션 감소 설정에서는 기능을 유지한다.
온보딩은 실제 단계와 대상 요소를 연결하고 건너뛰기·다시 보기·완료 상태를 검증한다.
모바일 실제 제스처를 검증하지 않았다면 코드 검사만으로 핀치 줌 검증 완료라고 보고하지 않는다.

출처: woori product requirements. 원본 절차를 프로젝트에 맞게 재작성했으며 프레임워크 구조/명명 규칙은 가져오지 않았다.
